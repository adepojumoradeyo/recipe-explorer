# Recipe Explorer 🍽️

Recipe Explorer is a recipe discovery application built with Next.js. It allows users to search for meals, explore recipes, and view detailed cooking instructions.

## Features

- Search for recipes by meal name.
- Browse recipe cards with food images.
- View individual recipe details.
- Display ingredients and measurements.
- View cooking instructions.
- Custom 404 page for recipes that cannot be found.
- Loading spinner while recipes load.
- Responsive design for different screen sizes.

## Technologies Used

- Next.js (App Router)
- React
- TypeScript
- Tailwind CSS
- TheMealDB API

## API

Recipe Explorer uses [TheMealDB API](https://www.themealdb.com/api.php) to retrieve recipe information.
